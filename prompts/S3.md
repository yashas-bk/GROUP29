# Prompt Log – S3

## Prompt 1

For PPL Assignment 2, Problem 2 (file id_q2.pl, SWI-Prolog 9.x, only libraries lists/apply/yall/aggregate, no assert/retract/global variables, nothing printed). Write one predicate: split_nonempty(List, Left, Right), which succeeds for every way of splitting List into two NON-EMPTY parts Left and Right with append(Left, Right, List), keeping the order. It must simply fail for lists of length 0 or 1. Give a short declarative reading of it in a comment and a few example queries.

## Prompt 2

Next predicate for id_q2.pl: apply_op(Op, A, B, V), where Op is one of +, -, *, / and A, B are integers. V is the integer result. For / it must succeed only if B =\= 0 and the division is exact (A mod B =:= 0, using integer division //), and fail otherwise. It must never raise an error. Also write op_symbol(Op) that enumerates the four operators in the order + - * /. Add a declarative reading as a comment.

## Prompt 3

Next predicate for id_q2.pl: expr(Nums, Tree, Value). Nums is a non-empty list of non-negative integers. On backtracking it generates every expression tree that uses all of Nums exactly once and in order, together with its integer value. A tree is either a number N (when Nums = [N]) or a term op(Op, LeftTree, RightTree), built by splitting Nums with split_nonempty/3 and joining the two sub-expressions with one operator through apply_op/4. There is no unary minus and numbers are never joined into bigger numbers. Negative intermediate values are allowed. Every division at any depth must be exact with a non-zero divisor; this follows from using apply_op/4. Use split_nonempty/3 and apply_op/4 from the earlier prompts. Explain why it terminates and why each tree is produced exactly once.

## Prompt 4

Next predicate for id_q2.pl: prec(Op, P), giving precedence 1 for + and -, and 2 for * and /. Also write tree_prec(Tree, P): a number has the highest precedence (use 3), and op(Op,_,_) has the precedence of Op.

## Prompt 5

Next predicate for id_q2.pl: tree_string(Tree, String), which turns a tree from expr/3 into an SWI-Prolog string (not an atom, not a code list) with no spaces, numbers in decimal. Parenthesise by exactly this rule: * and / bind tighter than + and -; operators are left-associative; a LEFT operand gets parentheses only if its top operator has LOWER precedence than its parent's; a RIGHT operand gets parentheses if its top operator has the SAME OR LOWER precedence than its parent's; a single number is never parenthesised. Use prec/2 and tree_prec/2. Build the string with string concatenation or format(string(S), ...). Do not build a string and parse it back. Check it against: (4+2)*3, 4+2*3, 8/4*2, 8/(4*2), 1-2-3, 1-(2-3), 1+(2+3), 1+2+3.
