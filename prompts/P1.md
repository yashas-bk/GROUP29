# P1 Prompts: Department Assignment Puzzle (id_q1.pl)

## Prompt 1: Generator (solution/1)

Take a look at the problem statement about the department puzzle with Alex, Ben, Carla and Dana. Can you write just the solution/1 predicate that generates all possible assignments without applying any clues yet? I'll need every candidate later for counting.

## Prompt 2: Clues (clue/2)

Now write clue/2 with one clause for each of the 8 clues, assuming the solution is fully filled in when it's called. Here are the clues:
1. The friend who prefers the AI project does not work in research and is not Dana.
2. Alex does not work in development and does not prefer C++.
3. The friend working in the testing department likes Python.
4. Ben prefers web projects and does not work in testing.
5. The friend whose favorite language is Java works in the design department.
6. Carla's project preference is not embedded, and her department is not development.
7. Dana's favorite language is not Java, and she works in research or testing.
8. The friend who prefers data projects works in research and does not use JavaScript.

## Prompt 3: Solve (main/0)

Write main/0 that finds the solution satisfying all 8 clues and prints it in the required four-line format. Don't hard-code anything.

## Prompt 4: Count (count_solutions/2)

Write count_solutions(Active, N) that counts how many candidates satisfy exactly the clues in Active.

## Prompt 5: Repair (clue 9)

With clues 1–8 I get N = 3, and these are the solutions: [p(Alex,design,java,AI),p(Ben,development,javascript,web),p(Carla,research,c++,data),p(Dana,testing,python,embedded)], [p(Alex,design,java,embedded),p(Ben,development,javascript,web),p(Carla,testing,python,AI),p(Dana,research,c++,data)], [p(Alex,testing,python,embedded),p(Ben,development,javascript,web),p(Carla,design,java,AI),p(Dana,research,c++,data)]. Give me a 9th clue that leaves only one solution, without naming any friend.

## Prompt 6: Tests (tests/test_q1.pl)

Write a plunit test file for P1 covering the clues, the counts and main's output. Also tell me how to run it.

## Prompt 7: Report (P1_REPORT.md)

Write a short P1_REPORT.md explaining what N is for clues 1–8, what that says about the puzzle, and how clue 9 fixes it.
