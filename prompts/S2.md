## Prompt 2: insert-if-short
Read skills/scheme-dev/SKILL.md and follow it.

In code/29_q4.rkt, add (insert-if-short x lst n), built with my-length and my-map. Don't change the existing helpers.

Behaviour:
- Insert x at the front of every list whose length is less than n, at every level of nesting. This includes the top-level list.
- Length means the number of top-level elements of the ORIGINAL list, measured before any insertion.
- An element counts as a list if (or (null? e) (pair? e)) is true, so () counts as a list and becomes (x) when 0 < n. Atoms are returned unchanged.
- Recurse into the sublists with my-map first, then decide whether to cons x onto the result, using my-length of the original list.

Rules:
- Use only the allowed built-ins from the skill file.
- No top-level calls, nothing printed on load, and the file ends with a newline.
- Put the purpose comment and the recursive reading above the define.
